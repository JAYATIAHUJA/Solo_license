// the loop

A simple, elegant control loop — that never trusts a tool's word.

One refund run does exactly this, in order, tracing every step. Authority comes from the license; truth comes from reading the database back.

01

License check

Read the task class's rung on the ladder before doing anything.

02

Execute or suggest

Do only what the license authorises — suggest, draft, or auto-execute.

03

Verify in SQLite

Read the actual side effect back. The tool's response is never evidence.

04

Update the dial

A verified-clean run earns credit; the track record climbs the ladder.

detection fires

If any detection fires, the class crashes to L0 and is quarantined — then a human reviews one evidence packet and restores it with judgement, not a blind retry.

// the autonomy ladder

Four rungs. Earned one clean run at a time.

Promotion is automatic after N consecutive verified-clean runs. Demotion is immediate on a detection. The dial is always the single source of truth.

rung 00
L0

Suggest only

The agent recommends; a human does everything. Near-zero autonomy — the starting line.

rung 01
L1

Draft + approve

The agent prepares the change and holds. A human approves every execution.

rung 02
L2

Auto under ceiling

The agent acts automatically below a dollar ceiling. Humans spot-check.

rung 03
L3

Full auto, audited

Full autonomy with post-hoc audit sampling — earned, and revocable in an instant.

// detections drive demotion

Three checks stand between the agent and your ledger.

Pure, testable rules that fire on observed facts. When one fires, the dial drops — no exceptions, no overrides.

state_mismatch

intended Δ $40.00
sqlite moved $0.00

The verified change in the database doesn't equal what the agent intended — the signature of a quiet failure.

▸ demotes to L0

policy_breach

authorised: DRAFT
attempted: AUTO_EXECUTE

The agent executed beyond what the license authorised. The ceiling and level are folded into one decision.

▸ demotes to L0

missing_verification

executed: true
verified: false

An execution completed without ever reading SQLite back. If it wasn't verified, it didn't happen.

▸ demotes to L0
