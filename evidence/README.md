# Artifacts

Judge-verifiable evidence produced by the real system. Everything here is
regenerated by commands you can run yourself; nothing is hand-written.

| File | How to regenerate | What it shows |
|---|---|---|
| `benchmarks/coding_before_after.md` / `.json` | `make coding-benchmark` | One coding session (3 days x 5 requests) replayed through the real gate: permission prompts 21 -> 11, actions that ran without a prompt 0 -> 19 (earned), force-pushes to main 3 prompts -> 3 denied, over-edited lines reaching review 157 -> 0. Includes every turn's decisions and the license events |
| `claims.json` | checked by `bash scripts/verify.sh` | Every claim the README makes about the system, each with the command that machine-checks it |
| `entire.md` | - | How Entire is used: ledger commits, checkpoints, Trails on every PR, graph output |

`bash scripts/verify.sh` runs every claim in `claims.json` and prints
PASS/FAIL for each; it is also a CI step, so the README's numbers cannot
drift from the code without the build going red.

The license ledger itself lives in the repo:
`git log --oneline -- ledger/license_ledger.jsonl` shows how each action
class earned and lost its license. The earliest entries are the v1 payments
agent (the same engine, first domain); current entries are the coding gate.
